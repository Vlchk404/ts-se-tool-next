# ETS2 / ATS Save Editor

Редактор сохранений **Euro Truck Simulator 2** и **American Truck Simulator**
для версий игры **1.60.1.7 и новее**. Графическое окно и командная строка,
только стандартная библиотека Python, резервная копия перед каждой записью.

[English version](README.en.md)

Зачем он нужен: TS SE Tool 0.3.11.0 официально поддерживает игру только до 1.49
и на сохранениях 1.60 ломается при записи. Этот редактор читает и пишет формат
1.60.1.7 (`version: 97`) напрямую. У ETS2 и ATS формат сохранений общий, поэтому
редактор работает с обеими играми.

## Что умеет

- **Деньги, опыт, игровое время, название сохранения.**
- **Навыки водителя:** ADR (0–6 классов) и пять остальных умений
  (`long_dist`, `heavy`, `fragile`, `urgent`, `mechanical`) — по одному или всё
  сразу на максимум.
- **Кредиты:** списать все, изменить лимит.
- **Техника:** полный ремонт всех машин и прицепов, включая «неустранимый»
  износ; полные баки; восстановление груза; пробег и номер выбранного грузовика.
- **Мир:** открыть все города, автосалоны и агентства найма; купить и расширить
  все гаражи до 5 мест; поднять навыки всех наёмных водителей и задать им
  политику обучения.
- **Вкладка «Всё подряд»:** любые юниты и поля сохранения напрямую — то, чего
  нет в готовых кнопках, и запас на будущие версии игры.
- **Резервные копии:** делаются перед каждой записью, восстанавливаются одной
  кнопкой.

## Требования

- **Python 3.8 или новее.** В установщике с python.org поставьте галочку
  «Add python.exe to PATH». Больше ничего ставить не надо: пакет использует
  только стандартную библиотеку. Шифрование сохранений редактор снимает
  средствами самой Windows (CNG), так что скорость не зависит от сторонних
  библиотек; если в системе уже есть `cryptography`, она тоже подойдёт.
- **Euro Truck Simulator 2 или American Truck Simulator 1.60.1.7+.** Более
  старые сохранения редактор откроет, но проверялся он на 1.60.1.7.
- **Windows 7 и новее** — окно рассчитано на Windows, проверено на Windows 10 и
  11, масштабирование экрана (125 %/150 %) учитывается. Командная строка
  работает на любой системе, где видны папки профилей игры.

## Установка

Скачайте архив кнопкой **Code → Download ZIP** и распакуйте в любую папку — или
склонируйте репозиторий:

    git clone https://github.com/Vlchk404/ts-se-tool-next.git

## Запуск

Двойной щелчок по **`Редактор ETS2.bat`** — откроется окно редактора. Файл
только запускает Python, ничего не устанавливает.

То же самое из командной строки, из папки проекта:

    python -m ets2se                 # окно редактора
    python -m ets2se list            # какие есть профили и сохранения
    python -m ets2se show "MyProfile/1"

## Порядок работы

1. **Выйдите из игры** — хотя бы из загруженного профиля. Игра держит
   сохранение в памяти и перезапишет ваши правки при следующем автосейве.
2. Выберите сохранение в списке слева, поправьте значения, нажмите
   **«Применить и сохранить»**.
3. Копия всей папки сохранения уходит в
   `<профиль>/ets2se_backups/<сохранение>_<дата>`. Если что-то пошло не так —
   вкладка **«Резервные копии»** и кнопка восстановления.

## Командная строка

    python -m ets2se list
    python -m ets2se show "MyProfile/1"
    python -m ets2se edit "MyProfile/1" --money 5000000 --xp 900000 --all
    python -m ets2se edit "MyProfile/1" --money 5000000 --dry-run
    python -m ets2se backups MyProfile
    python -m ets2se restore <папка_копии> "MyProfile/1"
    python -m ets2se doctor

Сохранение можно указать полным путём к папке, как `профиль/сохранение` или
просто именем, если оно одно такое.

Основные ключи `edit`:

| Ключ | Что делает |
| --- | --- |
| `--money N`, `--add-money N` | задать или добавить деньги |
| `--xp N`, `--add-xp N` | задать или добавить опыт |
| `--skills-max` | все навыки водителя на максимум |
| `--adr N` | классы ADR, 0–6 |
| `--skill ИМЯ=УРОВЕНЬ` | навык поштучно, например `--skill heavy=6` |
| `--clear-loans`, `--loan-limit N` | списать кредиты, изменить лимит |
| `--repair`, `--keep-unfixable` | ремонт всей техники; второй ключ оставляет «неустранимый» износ |
| `--refuel`, `--fix-cargo` | полные баки, восстановить груз |
| `--unlock-cities`, `--unlock-dealers`, `--unlock-recruitments` | открыть города, автосалоны, агентства найма |
| `--garages [СТАТУС]` | все гаражи: `3` большой на 5 мест (по умолчанию), `6` стартовый, `0` не куплен |
| `--drivers-max`, `--driver-policy ИМЯ` | навыки наёмных водителей и политика обучения (`eco`, `long`, `adr`, …) |
| `--game-time МИНУТЫ`, `--rename ИМЯ` | игровое время, название сохранения |
| `--all` | навыки, ремонт, топливо, груз, кредиты и все открытия сразу |
| `--dry-run` | показать, что будет сделано, и ничего не писать |
| `--no-backup` | не делать резервную копию (не рекомендуется) |

Полный список — `python -m ets2se edit --help`.

## Резервные копии

Перед каждой записью редактор копирует всю папку сохранения в
`<профиль>/ets2se_backups/<сохранение>_<дата>`. Восстановление — вкладкой
«Резервные копии» или командой:

    python -m ets2se backups MyProfile
    python -m ets2se restore <папка_копии> "MyProfile/1"

Копии никуда не отправляются и ничего не удаляют — это обычные папки, их можно
скопировать или стереть вручную.

## Если игра не находится

Редактор ищет `Documents`, `Документы` и вариант, перенаправленный в OneDrive,
внутри — `Euro Truck Simulator 2` и `American Truck Simulator`, а в них
`profiles` и `steam_profiles` (профили Steam Cloud помечены `[S]`). Если папка
лежит в необычном месте, укажите её прямо:

    set ETS2SE_DOCUMENTS=D:\путь\к\Documents
    python -m ets2se list

## Если что-то не так

Первым делом — проверка окружения:

    python -m ets2se doctor

Она печатает версию Python, разрядность, версию Windows, какой AES используется,
есть ли tkinter и какие папки игры нашлись. Этого обычно хватает, чтобы понять
причину.

- **Окно «не отвечает» и закрывается с отчётом Windows.** Так вело себя всё до
  версии 1.2 на машинах без библиотеки `cryptography`: сохранение расшифровывалось
  чистым Python прямо в потоке окна, и Windows успевала посчитать программу
  зависшей. Теперь расшифровка идёт средствами Windows, а чтение вынесено в
  отдельный поток — окно остаётся живым. Если строка состояния внизу пишет
  «AES: чистый Python», значит Windows CNG почему-то недоступен: сохранения
  всё равно откроются, просто медленнее.
- **Двойной щелчок по `Редактор ETS2.bat` открывает Microsoft Store.** Это
  заглушка Python из магазина: она лежит в `PATH`, но ничего не запускает.
  Установите Python с python.org — лончер сам обходит заглушку, если рядом есть
  настоящий Python.
- **Мелкий или мыльный текст** на ноутбуке с масштабом 125 %/150 % — редактор
  сообщает Windows о поддержке масштабирования сам, отдельных настроек не нужно.


## Как это устроено

Игра пишет `game.sii` зашифрованным (`ScsC`). Редактор читает такие файлы, но
записывает **расшифрованные**: двоичный `BSII` остаётся двоичным, текстовый
`SiiNunit` — текстовым. Игра сама грузит все три варианта, незашифрованные
`profile.sii`, `controls.sii` и `def`-файлы игры — тому доказательство.

Расшифровка берётся из того, что есть в системе, в порядке убывания скорости:
AES самой Windows (CNG, `bcrypt.dll` — есть в любой Windows начиная с Vista и
использует аппаратное ускорение), затем библиотека `cryptography`, если она
установлена, и только в крайнем случае — реализация на чистом Python. Последняя
написана на четырёх обратных T-таблицах и примерно в 57 раз быстрее наивной
формы, но всё равно заметно медленнее первых двух. Какая из них работает сейчас,
видно в строке состояния окна и в `python -m ets2se doctor`.

Чтение сохранения (расшифровка плюс разбор файла, а это до 7 МБ и больше 20 000
блоков) идёт в отдельном потоке: окно продолжает отвечать, поэтому Windows не
считает программу зависшей. Запись и копирование резервной копии — тоже.

Ничего лишнего при записи не меняется: каждое незатронутое поле пишется теми же
байтами, что были прочитаны. На корпусе из 72 реальных сохранений цикл
«декодировать → закодировать» даёт файл, идентичный исходному до байта. Формат
никогда не переводится из двоичного в текстовый и обратно — в текстовом виде
теряется упаковка секторов у координат.

Игра читает `game.sii` через `load_unit_tree()` и требует, чтобы все блоки файла
были связаны ссылками в **одно дерево**. Блок, на который никто не ссылается, —
это второй корень, и загрузка падает с `There are multiple unit trees in the
file`, а в игре — «Возникла проблема при загрузке сохранённой игры». Поэтому
редактор никогда не выбрасывает ссылку, оставляя блок: списание кредитов удаляет
и сами блоки `bank_loan`, а уменьшение гаража сохраняет все занятые места. Перед
каждой записью структура проверяется заново, и если бесхозные блоки всё же
появились, запись отменяется с ошибкой — файл остаётся прежним.

## Проверка

    python -m unittest discover -s tests

Синтетические тесты кодеков идут всегда; тесты на реальных сохранениях
пропускаются, если игра на машине не найдена. Правки в тестах применяются к
временной копии, файлы игры не затрагиваются.

## Чего нет

Найма новых водителей, покупки новой техники и правки самих заказов. Это не одно
поле, а согласованный набор юнитов и параллельных массивов, и ошибка там портит
сохранение молча. Существующих водителей, машины и гаражи редактор меняет
полностью.

## Осторожно

Правка сохранений — не то, что предусмотрено разработчиками игры. Перед первым
запуском лучше скопировать папку профиля целиком, а после правки — загрузить
сохранение и убедиться, что всё на месте. Резервную копию редактор делает сам,
но ответственность за содержимое сохранения остаётся на вас.

Проект никак не связан со SCS Software. Euro Truck Simulator 2 и American Truck
Simulator — торговые марки SCS Software.
